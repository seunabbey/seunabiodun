# Seun Abiodun Portfolio Revamp

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript. No framework, build step, or package installation is required.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive layout, visual styling, theme and accent palettes
- `script.js` — mobile navigation, theme preferences, accent selection, back-to-top control, FormSubmit email enquiry form, and small scroll reveals

## Publish on GitHub Pages
1. Download and unzip this folder.
2. Open your `seunabbey.github.io` GitHub repository.
3. Upload/replace `index.html`, `styles.css`, `script.js`, and `seunabiodun.png` in the repository root.
4. Commit the changes. GitHub Pages should publish automatically if already enabled.
5. Open `https://seunabbey.github.io/` and hard-refresh if the old version is cached.

## Before publishing
- Verify that each project description accurately reflects your role and contribution.
- Confirm that project URLs are still live and that you have permission to showcase them.
- Replace the abstract project visuals with optimized screenshots if you have permission and want to show actual work.
- The contact form submits enquiries through FormSubmit to `oluwaseunabiodun100@gmail.com`. Confirm the FormSubmit activation email sent to that inbox before accepting enquiries, and test the live form after publishing.
- The Google Fonts link is optional. If you want zero external font requests, remove it from `index.html`; system fonts will be used as fallback.

## Design features
- Dark and light modes
- Four accent palettes: violet, cyan, amber, emerald
- Sticky header with theme controls and mobile navigation
- Back-to-top button
- Responsive service, project, and contact layouts
- Reduced-motion support and keyboard focus styles
- No external JavaScript dependencies
